# Any Disc
A Minecraft tool for making your own custom music discs!

## **Using the Tool**

### **Releases**
Releases are currently only for windows x86.

### **Adding Images to Image List (1st Column)**
Images must be .png, there is already an existing default Image for Any Disc custom discs. Select any amount of .png Images to add to the list of Images.

**\*Note\*** If you add 2 Images that have the same name, the tool will mark them as duplicates and cannot create your packs. Remove one of the duplicates.

### **Adding Songs to Song List (2nd Column)**
Songs must be .ogg, select any amount of .ogg files to add to the list of Songs.

**\*Note\*** If you add 2 Songs that have the same name, the tool will mark them as duplicates and cannot create your packs. Remove one of the duplicates.

### **Creating Discs (4rd Column)**
Each discs requires a name, Song and an Album. 

#### **Name**
This name is how the Song will be seen in Minecraft.

#### **Adding a Song**
Just as with **Adding Songs to the Song List**, select a .ogg Song for that disc, and then that Song will be attached to that disc and be added to the Song List.

#### **Albums (3rd Column)**
Albums are ways to allow all discs of the same Image to be shared. When obtaining new discs, all discs within a single Album are equally likely to drop, and all Albums are equally likely to drop.
Creating Album requires a name and the associated Image. selecting a .png for that Image will add that Image to the Image list.

For adding an Album to a disc, select the desired Album from the dropdown menu. If the name of that Album changes, the disc will indicate that it cannot find an image for the disc.

#### **Direct Matching**
When you don't want to use an Album, ensure that the name of the files for the Image and Song are the same for a singular disc. This is noted in the application. Then ensure the selected Album for the disc is *blank*, **NOT** default.

### **Creating Packs**
Ensure there are now errors in the previous columns, which will be indicated by red text. The red text will explain the issue. Once there are no red text errors, pressing the **Create Packs** Button should successfully create a zip file 
in the same location as the application.

## **OBTAINING CUSTOM DISCS IN MINECRAFT**
To obtain the new music discs, you must give yourself a breeze rod and enchant it with **Mark of Music**, a new enchantment specific to Any Disc. by putting this enchanted breeze rod in your offhand, you have a 100% disc drop rate from creepers. Currently, you cannot use an enchantment table to enchant a breeze rod with Mark of Music, it must be done with `/enchant @s any_disc:mark_of_music`.
